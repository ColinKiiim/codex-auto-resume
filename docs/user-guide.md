# CodexAutoResume 使用指南

[首页](../README.md) · [常见问题](troubleshooting.md) · [English overview](../README.en.md)

## 安装与首次启动

从本仓库 Releases 下载 `CodexAutoResume-v版本-windows-x64.exe`，双击即可。使用 Windows 10 1903+ / Windows 11 x64 和系统 .NET Framework；程序的图片、图标与许可证均已内嵌。问答识别使用已安装的 Windows OCR 语言。

打开 Codex，等待工具识别窗口和右下角按钮。启动默认仅观察；核对目标后勾选“允许自动点击”开始。只有一个合适窗口时自动连接，多个目标窗口需选择。选项和连接不跨启动保存。

## 前台与后台模式

前台模式要求 Codex 位于前台，按钮可见。勾选“后台模式”后，可以切到其他应用并把 Codex 完全盖住，保持 Codex 未最小化、未隐藏。后台通过窗口消息操作，不移动系统鼠标或激活目标。两个程序使用相同普通用户权限。

后台模式需要目标持续提供更新画面并接受消息。可以先用“后台自测”检查本机路径，再核对实际 Codex 暂停场景。最小化后等待还原。黄色边框是 Windows 的捕获指示，详见 [后台模式](background-mode.md)。

## 窗口移动与多个候选

自动定位跟随窗口移动。“选择窗口”可更换目标；“选择区域”可主动选择按钮区域。

多个按钮候选出现时，只暂停点击，继续扫描。恢复单候选后自动继续原工作模式。取消区域选择也继续扫描。已经人工确认的区域按原位置跟踪；原区域消失或窗口布局变化时，可重新选择。蓝色数字引用等未知图形不进入自动候选。

## 监测与点击规则

普通图标检测约每 400ms 一次；问答状态约每 2 秒检查一次。右三角形连续稳定出现后，点击前独立核对一次。恢复尝试至少间隔 5 秒，白色运行方块用于确认成功。

发送箭头、声波和方块只观察；问答面板等待用户作答。临时捕获失败、拖动窗口、无法识别和未确认方块时持续监测。点击“停止”或关闭窗口才结束日常监测。

## 状态提醒与日志

“状态提醒”可选每 1 分钟或 5 分钟，默认 1 分钟。即使图标不变，也能看到程序仍在工作，无弹窗通知。

“打开日志”打开 `%LOCALAPPDATA%\CodexAutoResume\logs`。`events.log` 记录状态和界面心跳，`diagnostics.log` 每 10 秒记录取样、缓存、新帧时间、异常与恢复计数。每类日志保留约 2 MiB 当前文件和一个历史文件。

超过 5 秒的原始画面不用于点击或方块确认。界面显示“状态待确认”并尝试恢复捕获；旧预览不代表当前状态。字段解释见 [日志说明](monitoring-logs.md)。

## 自检与演示

| 功能 | 用途 |
|---|---|
| 本机自检 / F2 | 检查系统接口、内嵌资源、任务栏身份和用户数据目录 |
| 后台自测 / F4 | 用工具自己的按钮与遮挡窗口验证后台恢复路径 |
| 打开演示 | 测试按钮状态、双区域和位置变化 |
| 保存局部诊断图 | 主动保存上一帧按钮区域，用于识别排查 |

后台自测期间暂勿移动鼠标或切换窗口。可关闭遮挡窗口或使用停止快捷键取消。自测暂停日常监测，完成后点“开始观察”恢复。

## 可选快捷键与备用标定

日常使用不需要快捷键。自动定位不适用时，可以手动标定：

| 功能 | 默认组合 |
|---|---|
| 连接当前前台 Codex，使用自动定位 | Ctrl+Alt+F8 |
| 鼠标放到按钮中心后手动标定 | Ctrl+Alt+F7 |
| 开始 / 暂停 | Ctrl+Alt+F9 |
| 停止 | Ctrl+Alt+F10 |

被占用时依次尝试 Ctrl+Alt+Shift、Ctrl+Shift，以主窗口显示为准。手动标定记录窗口内坐标，移动后跟随；改变窗口尺寸或 DPI 后重新标定。F8 可回到自动定位。区域选择没有默认选中项。

## 换电脑

只复制一个 EXE，放到任意可读取位置启动，程序目录可以只读。日志写入当前用户的 LocalAppData。图标识别不需要外部图片或开发环境；问答 OCR 需要相应的系统识别语言。

反馈问题时提供工具与 Codex 版本、Windows 版本、显示缩放、工作模式和复现步骤。详细排查见 [FAQ](troubleshooting.md)。
