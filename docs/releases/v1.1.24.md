# CodexAutoResume v1.1.24

2026-10-30

## 变更

- 自动检查新版本改为每小时一次，保留启动检查、手动检查和无更新时静默
- 重新整理首页：状态与操作保持可见，剩余额度独立显示在最近进度之前，恢复次数归入进度区
- 设置分为常规、监测与恢复、额度、定时与任务、诊断、关于与更新；保留主窗口内导航，长页独立滚动
- 额度继续指令改为明确保存，未保存的编辑不改变执行状态；一次性任务使用独立编辑窗口，保存前核验并绑定当前聊天

## 修复

- 修复首页整页滚动挤走额度、滚动后隐藏状态与暂停按钮的问题
- 修复额度阈值被拆散、长说明/按钮与窗口尺寸不协调的问题，统一记录、诊断、更新和选择窗口的布局
- 修复界面翻译或重建控件时重置时间选择器、影响定时设置的问题；保留输入内容与任务选择
- 额度详情支持复制，刷新时保留阅读位置；更新结果可在关于页直接查看

保持 1.5 秒输入让行、普通恢复不读取草稿以及原目标/账号/恢复确认保护。额度控制默认关闭，真实后台发送、服务端额度重置及部分设备缩放仍按 TODO 继续验收。

## Changed

- Check for new versions hourly, retaining startup/manual checks and quiet background results
- Keep monitoring status and controls visible, place remaining usage above recent progress, and group the recovery counter with progress
- Organize Settings into six categories with persistent navigation and independent scrolling for long pages
- Save quota continuation edits explicitly without changing execution while typing; edit scheduled tasks in a dedicated window and verify the current chat before saving

## Fixed

- Remove whole-page monitoring scroll that pushed usage offscreen and hid status and Pause while scrolling
- Keep threshold fields together and adapt text, controls, history, diagnostics, updates and selection windows to available space
- Preserve date/time selections, editor contents and task selection during localization and control construction
- Allow copying usage details while preserving reading position during refresh; show update-check results inline

Retains the 1.5-second input pause, draft-free ordinary recovery and existing target/account/confirmation safeguards. Quota control stays off by default. Real background submission, server quota-reset recovery and some device scaling scenarios remain under verification in TODO.
