# CodexAutoResume v1.1.18

2026-10-28

## 新增

- 设置 → 诊断工具新增“复制近 30 分钟日志”和“导出近 30 分钟诊断包”。复制包含文本；ZIP 包含时间段内文本、环境信息及已保存且仍保留的原始捕获帧、按钮图和关联记录
- “详细诊断（含原始窗口截图）”默认关闭，本次开启最多 1 小时。后台监测利用已有捕获保存原始分辨率 PNG、完整 SHA256、捕获来源/序号、分类分数、窗口身份及输入空闲信息；截图按 180 组 / 128 MB 滚动，忙时跳过保存，不堆积图片任务
- 可另选“只读 UIA 对照”，以有截止时间的独立进程记录文档/选中聊天的标题摘要及已知按钮计数，不读取正文、输入或点击。默认关闭，便于先保留原有重绘行为复现问题

## 变更

- 文本日志补充应用/目标版本、窗口可见/最小化/前台属性和捕获/分类关联，区分“新系统帧时间”与“任务状态确实更新”
- 诊断数据只保存在本机，不自动上传；截图可能包含私人聊天，分享前应检查。复制/导出仅包含指定日志与证据，不打包设置、账号凭据或一次性指令存储

## 复现方法与边界

先开启详细诊断，暂不勾选 UIA 对照，再用其他窗口完全遮挡目标，保持目标未最小化。出现“实际暂停但仍显示运行中”时先等约 15 秒记录，随后切回目标观察变化，点击导出近 30 分钟诊断包。完整步骤见[诊断日志说明](../monitoring-logs.md)。

本版用于排查另一设备的完全遮挡暂停漏检，未宣称根因已修复；保留原恢复路径及连续 1.5 秒输入让行。最小化操作仍待实现。图像按容量滚动，不能保证覆盖完整 30 分钟；只会导出开启期间实际保存的可用图像。

## Added

- Copy the last 30 minutes of text logs or export a ZIP with recent logs, environment metadata and available retained capture evidence
- Opt-in detailed diagnostics retain original-resolution PNG frames, button crops, full SHA256 digests and capture/classification/target correlation. Recording lasts up to one hour per enable and rotates at 180 sets / 128 MB with one bounded image worker
- Optional read-only UIA comparison runs in a separate process with a deadline, records hashed document/selected-row titles and known-button counts, and never reads message bodies or performs input. It is disabled by default to preserve the initial reproduction conditions

## Changed

- Text diagnostics now distinguish capture activity from proof of current task state and include app/target versions and window state
- Diagnostic data stays local. Review private chat content in images before sharing. Exports allowlist logs and evidence, excluding settings, credentials and saved task instructions

This release adds diagnostics for the reported occlusion issue; it does not claim a fix. The existing recovery path and 1.5-second input-idle rule remain. Minimized operation is still pending. Images may cover less than 30 minutes because of opt-in recording and rolling retention.
