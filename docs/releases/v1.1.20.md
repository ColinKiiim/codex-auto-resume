# CodexAutoResume v1.1.20

2026-10-29

## 修复

- 完整包含 1.1.19 的遮挡旧画面处理、多页面/输入区绑定、可核验接口下的最小化恢复与后台输入，以及更详细的诊断
- 补齐后台问答的导航保护：检测到等待用户处理时，项目展开、聊天切换、范围轮询与一次性任务同样等待；独立导航辅助进程在投递前重新核验，防止主窗口状态尚未同步时切走聊天

继续保留连续 1.5 秒输入空闲、草稿保护和不明结果不重发。最小化操作需要目标已有且归属/聊天均可核验的 CDP 接口；不可用时等待，不自动开启调试、重启或还原目标。故障设备完全遮挡/最小化与真实后台发送仍待用户验收。

1.1.19 的完整变化及支持条件见[上一版说明](v1.1.19.md)，本次验证见[补充记录](../history/2026-10-29-v1.1.20-navigation-guard.md)。

## Fixed

- Includes the verified background-control, stale-capture handling, multiple-page binding, minimized-operation and diagnostic changes from 1.1.19
- Pending questions now also block project expansion, chat switching, scoped polling and timed instructions. The independent navigation worker rechecks this immediately before dispatch, including when the main monitor has not yet observed the question

The 1.5-second input-idle rule, draft protection and uncertain-submission handling remain. Minimized operation requires an existing ownership-verified CDP endpoint with a proven conversation; unavailable endpoints wait without enabling debugging, restarting or restoring the target. The affected PC and real-app background submission still require acceptance. See the [1.1.19 notes](v1.1.19.md) for the full support conditions.
