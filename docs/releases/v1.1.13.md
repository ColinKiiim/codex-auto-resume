# CodexAutoResume v1.1.13

发布日期：2026-10-26（UTC+8）

## 中文

### 新增

- 首页底部用两条短进度条显示当前本机 Codex 登录账号的剩余额度，不增加大面积卡片
- 点击额度摘要查看账号来源、窗口重置时间和最近更新时间，并可手动刷新

### 改进

- 手动选择窗口移到“设置 → 常规 → 高级定位”，首页保留当前目标名称
- 额度后台读取复用本机 Codex 登录；查询失败时标记旧数据或不可用，自动恢复继续工作

### 已知问题

额度读取需要本机 Codex 安装提供兼容组件；自定义登录环境请核对详情中的账号与来源。第二台实体电脑的额度兼容和原遮挡故障场景专项复验尚未完成；目标重绘和系统捕获仍可能影响暂停识别

## English

### Added

- Compact footer bars show remaining quota for the current local Codex login without enlarging the home window
- Click the quota summary for account/source details, reset times, the last update and manual refresh

### Improved

- Manual window selection now lives under Settings → General → Advanced targeting
- Usage queries reuse the local Codex login in the background; failures mark old or unavailable data while auto-resume continues

### Known issues

Usage requires a compatible local Codex component. Verify account/source details for custom login environments. Quota compatibility on a second physical PC and the original covered-window reproduction remain unverified; target repainting and system capture can still affect pause detection
