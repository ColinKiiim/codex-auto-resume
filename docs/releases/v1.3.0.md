# CodexAutoResume v1.3.0

## 更新日志（中文）

## [1.3.0] - 2026-10-24

### 新增

- 新增后台模式，通过 Windows Graphics Capture 与 D3D11 获取被其他窗口遮挡的 Codex 画面。
- 支持向目标窗口发送后台点击消息，保持系统鼠标位置和前台窗口。
- 后台恢复后识别运行方块，保留多候选选择和手动标定入口。

## Changelog (English)

## [1.3.0] - 2026-10-24

### Added

- Add background capture through Windows Graphics Capture and D3D11 for covered Codex windows.
- Send background click messages to the target without moving the system pointer or changing the foreground window.
- Verify the running square after a background resume and retain candidate selection and manual calibration.
