# CodexAutoResume v1.1.8

发布日期：2026-10-25（UTC+8）

## 中文

### 新增

- 自动检查 GitHub 最新正式版；发现更新显示版本与说明，确认后自动下载、校验、替换和重启，失败时保留或恢复旧版。支持稍后、跳过版本和手动检查。
- 主页面保留小幅真实按钮预览；问答状态显示较宽的提示与操作区域，点击可放大查看。
- 最近 4 条带时间戳的工作进度，正常静止时每 10 秒补一条简短检查记录。

### 变更

- 精简主界面，统一按钮与对齐；诊断、自测、手动参数、帮助与更新集中到设置。
- 后台优先响应新帧；兜底检查降为 3 秒，仅恢复按钮出现时短暂加快稳定性复查。
- 普通启动仍仅观察；保存前后台方式、区域大小及更新偏好。更新重启后核实原目标身份，再恢复此前状态；无法核实时退回仅观察。

### 修复

- 正常静止不再因 5 秒没有新帧切换为待确认，也不因 15 秒静止反复重建捕获。
- 点击前独立获取新画面；点击之前的旧方块帧不能确认之后的恢复操作。
- 暂停期间修改选项保持暂停，消除隐式重新开始监测的行为。
- 问答预览包含提示与操作区；短操作文字未被 OCR 完整读出时仍保留操作角落。

### 移除

- 移除冗长的 1/5 分钟界面心跳选项；完整活动日志不再堆积周期性检查信息，详细诊断日志继续保留。

## English

### Added

- Check stable GitHub releases automatically. New versions prompt for confirmation before download, integrity checks, replacement and restart, with rollback on replacement or startup failure.
- Show a tightly cropped real button preview and a wider contextual preview for question panels, with click-to-enlarge.
- Keep four timestamped progress entries on the home window, including a short check-in every ten seconds during static periods.

### Changed

- Simplify and align the main window; move diagnostics, self-tests, manual parameters, help and updates into Settings.
- Prefer background frame events, with a three-second fallback and temporary stability checks only while a resume button is present.
- Persist monitoring mode and update preferences. Ordinary startup remains observation-only; update restarts revalidate the original target before restoring prior state.

### Fixed

- Keep normal static observations without five-second uncertainty warnings or fifteen-second capture rebuilds.
- Independently acquire action evidence and reject pre-click cached squares as recovery confirmation.
- Preserve pause when options change.
- Include question context and the action corner even if OCR misses a short action label.

### Removed

- Remove verbose periodic UI heartbeats and their interval selector. Repeated progress stays in the bounded home list; detailed diagnostic logs remain available.
