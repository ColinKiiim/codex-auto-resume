# CodexAutoResume v1.1.2

## 更新日志（中文）

## [1.1.2] - 2026-10-24

### 修复

- 为后台捕获增加 3 秒等待期限，避免捕获调用阻塞界面。
- 同一时间只保留一个捕获任务，避免超时任务堆积。
- 丢弃超时后返回的画面，避免使用迟到结果执行点击。

## Changelog (English)

## [1.1.2] - 2026-10-24

### Fixed

- Add a three-second capture deadline to keep the interface responsive.
- Allow only one capture worker at a time to prevent queued stalled requests.
- Discard late capture results instead of using them for clicks.
