# CodexAutoResume v1.1.4

## 更新日志（中文）

## [1.1.4] - 2026-10-25

### 新增

- 勾选“允许自动点击”即可开始，自动寻找 Codex 窗口，无需快捷键。
- 识别等待回答面板，兼容“跳过”和填写后的“提交”状态；回答后自动回到图标监测。

### 变更

- 复用后台捕获会话，减少反复启停造成的黄色边框闪烁。

### 修复

- 临时捕获失败、拖动窗口或未确认运行方块时持续监测，恢复按钮按间隔重试。
- 取消等待方块超时后停止监测的行为，支持较晚到达的运行确认。

## Changelog (English)

## [1.1.4] - 2026-10-25

### Added

- Start by enabling automatic clicking and discover Codex windows without a hotkey.
- Recognize question panels with Skip or Submit actions and return to icon monitoring after the panel closes.

### Changed

- Reuse background capture sessions to reduce outline flicker caused by repeated restarts.

### Fixed

- Keep monitoring through capture failures, window movement and unconfirmed running states, with spaced resume retries.
- Continue monitoring beyond the former confirmation timeout and accept a later running-square confirmation.
