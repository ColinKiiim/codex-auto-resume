# CodexAutoResume v1.5.3

## 更新日志（中文）

## [1.5.3] - 2026-10-25

### 修复

- 排除蓝色引用编号等未知图形，避免引用被列为按钮候选、干扰自动定位。
- 增加声波竖条形状检查，修复小尺寸数字可能被识别为声波的问题。

### 变更

- 简化历史版本列表与发布说明，方便查看更新内容和下载附件。

## Changelog (English)

## [1.5.3] - 2026-10-25

### Fixed

- Exclude unknown glyphs such as blue citation numbers so they do not interfere with automatic button selection.
- Check the waveform bar structure to prevent small numeric badges from being recognized as voice icons.

### Changed

- Simplify release history and notes for easier access to changes and downloads.
