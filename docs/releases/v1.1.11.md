# CodexAutoResume v1.1.11

发布日期：2026-10-25（UTC+8）

## 中文

### 改进

- 前后台统一等待连续 1.5 秒无鼠标或键盘输入再恢复，有输入重新计时
- 恢复操作不再移动真实鼠标，点击前再次核对输入与按钮状态
- 更新弹窗显示当前语言的简短摘要，正文不再默认选中，默认回车为“稍后”
- 增加低频独立画面核验，以及本地捕获对照导出，帮助排查遮挡后的状态停留
- 检查更新结果明确显示当前版本、线上正式版本和来源

### 已知问题

部分环境完全遮挡后，目标可能未及时重绘或捕获到旧画面；本版增加主动核验与诊断，但仍需在实际故障电脑验证，不能保证所有环境立即识别暂停

## English

### Improved

- Both modes wait for 1.5 seconds without mouse or keyboard activity before resuming; new input restarts the wait
- Resume through window messages without moving the real pointer, with a final input and button check
- Read localized update highlights without selected text; Enter initially chooses Later
- Independently verify unchanged background captures periodically and export local capture comparisons
- Update-check results show the current version, published version and source

### Known issue

Some covered targets may stop repainting or supply an old surface. This release adds proactive verification and diagnostics; the affected computer still needs validation, and immediate detection in every environment is not guaranteed
