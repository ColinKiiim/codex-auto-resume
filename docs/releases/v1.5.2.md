# v1.5.2 — 检测心跳、帧新鲜度与多候选自动恢复

发布：2026-10-25。

- 界面状态提醒可选每 1 分钟或 5 分钟；图标不变也会报告监测仍开启及新帧年龄，无弹窗通知。
- 新增每 10 秒的详细本机日志，记录取样/缓存/异常、新帧时间、目标进程和恢复计数，支持轮转与打开日志目录。
- 超过 5 秒的原始画面不用于点击或方块确认，显示状态待确认，持续监测并限速尝试恢复捕获。
- 暂时多候选不会自动弹出阻塞框或清除连接；恢复单候选后自动继续原模式。
- 主动手动选择区域仍可用，取消后继续扫描；保留已人工选择区域的跟踪约束。
- 版本化历史、MIT、独立任务栏和单 EXE 便携保持可用。
- 492 项回归、20 项发布保护、完整界面多候选/心跳/问答恢复流程及遮挡后台测试通过。

跨夜冻结场景已增加诊断与保守决策保护，但没有在用户的另一台电脑复现整夜运行；系统或目标应用停止绘制时，重建捕获不保证恢复画面。问答识别仍需对应 Windows OCR 语言。
