# CodexAutoResume v1.5.2

## 更新日志（中文）

## [1.5.2] - 2026-10-25

### 新增

- 新增每 1 分钟或 5 分钟的状态心跳，图标不变时也能查看监测进度。
- 新增每 10 秒记录一次的本机详细日志，支持日志轮转和打开日志目录。

### 修复

- 多个候选暂时出现时继续扫描，恢复单候选后自动继续原工作模式。
- 取消手动区域选择后继续监测，保持目标连接。
- 记录原始画面更新时间，画面过期时显示待确认并尝试恢复捕获。

## Changelog (English)

## [1.5.2] - 2026-10-25

### Added

- Add a one- or five-minute status heartbeat even when the detected icon stays unchanged.
- Add detailed local logs every ten seconds, log rotation and an Open logs action.

### Fixed

- Keep scanning during temporary ambiguity and resume the previous mode when one candidate remains.
- Keep the target connected and monitoring active after cancelling region selection.
- Track native-frame freshness and show an unconfirmed state while attempting capture recovery for stale content.
