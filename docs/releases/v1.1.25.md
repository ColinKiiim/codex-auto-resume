# CodexAutoResume v1.1.25

2026-10-31

## 修复

- 后台连接连续失败后自动重新发现原窗口的接口，核验同一聊天后可切换到 UIA 后备，无需手动暂停再开始；增加重新核验进度和诊断记录
- 聊天身份优先取自主输入区所属区域，排除其他区域和隐藏旧页面的元数据；真正身份冲突继续等待
- 重新绑定保留定时、额度及原操作确认状态；操作结果不明时继续核验，不因重连而重复投递

## 变更

- 设置改为独立窗口，六类设置固定显示在左侧，右侧展示当前分类和分组内容；取消默认窄窗口的分类下拉框
- 保留分类与阅读位置、未保存内容保护；关闭设置不停止监测，也不取消既有计划

保留 1.5 秒输入让行、普通恢复不读取草稿和最小化时必须有可核验接口的限制。已完成自有窗口回归，原故障聊天的实际复现及其他设备缩放验收继续记录在 TODO。

## Fixed

- Automatically rediscover the original window's background interface after repeated failures, using UIA fallback only after independently matching the conversation
- Resolve conversation metadata within the main composer's region and exclude unrelated or hidden views; keep real identity conflicts blocked
- Preserve schedules, quota ownership and pending action results across reconnection without repeating uncertain actions

## Changed

- Open Settings in a dedicated window with six persistent sidebar categories and a separate scrolling content area, replacing the category dropdown
- Retain navigation, reading position and unsaved-edit protection; closing Settings leaves monitoring and existing schedules intact

Retains the 1.5-second input pause, draft-free ordinary recovery and verified-interface requirement for minimized targets. Owned-window regression checks passed; the original incident and other device scaling scenarios remain under verification in TODO.
