## Windows 交互实测

通过 Computer Use 操作本工具的演示窗口：

1. 鼠标位于其他位置，按 Ctrl+Alt+Shift+F8，自动找到三角形，默认仅观察。
2. 开启自动点击后，自动恢复一次，按钮计数从 0 到 1，方块确认成功。
3. 用“换位置”将按钮从窗口右侧移到中间；再次切到三角形，工具自动找到新位置，计数到 2，方块确认成功。
4. 开启“双区域”，显示带编号上下文图和候选缩略图。未预选区域，确认按钮初始禁用。
5. 明确选择第二个方块区域并确认。另一区域保持三角形，计数仍为 2，未点未选区域。
6. 所选区域切到语音、发送，日志分别显示对应模式并保持不点击。
7. 回到单区域，最大化演示窗口；按钮随布局移到新的屏幕位置，重新切到三角形后自动恢复，计数到 3。
8. 鼠标放在按钮处按 Ctrl+Alt+Shift+F7，备用手动标定成功。
9. Ctrl+Alt+Shift+F10 停止成功。

另在真实 Codex 窗口执行只观察自动定位：F8 直接连接前台窗口，日志识别为“向上箭头：发送模式，保持观察，不点击”。未标定鼠标，也未点击真实聊天按钮；随后 F10 停止。真实暂停状态的恢复点击仍通过演示窗口验证。
