# 1.1.25 后台重新绑定与设置导航修复

用户在分析后明确要求开始两项修复，基于 1.1.24 实施并保持 1.1.x。原诊断与证据见[故障分析](2026-10-31-background-binding-analysis.md)；原 1.1.24 发布记录保持原样。

## 后台重新核验

- 原 CDP 绑定连续读取失败两次后，第三次观察不再携带旧页面/端口约束，重新发现当前目标进程拥有的接口；打开 CDP 失败时使用现有 UIA 只读后备。保留目标 HWND、PID 与进程启动时间边界，持续失败间隔由 5 秒逐步增加，最长 30 秒；仍使用单个有界辅助进程，不堆积捕获或连接。
- 新增只读观察的逻辑聊天比较：同一原生窗口与相同 CDP 聊天 ID 支持页面替换；跨后端必须有相同原生聊天证据与标题，不能凭标题相同通过。只有编辑器/文档 runtime ID 的 UIA 后备证明不用于跨后端匹配。动作仍使用严格的原页面、聊天与编辑器上下文。
- 保留旧绑定直至候选可核验；身份不明或存在未确认动作且候选不是原聊天时阻断。重绑不调用 Stop/Toggle，不改变 generation，不取消定时和额度所有权，不清空已尝试失败的记忆。
- 投递结果不明、投递中辅助进程断开或动作后确认阶段断连时保留独立阻断状态；只有原聊天的新 Running 观察解除，防止恢复连接被误解为可以重新投递。额度和定时的既有专用事务检查保留。
- 身份元数据优先从主编辑器最近的含元数据祖先区域取得；排除 aria-hidden/inert 和 CSS 隐藏祖先下的旧视图，仍允许合法零尺寸元数据。侧栏仅采用聊天项/聊天路由，不把其他 aria-current 导航项混入；区域内多 ID、与当前聊天侧栏冲突继续失败，不取第一个 ID。
- `control-unavailable` 新增连续次数、重新发现阶段与待确认动作状态；`control-rebound` 记录前后后端与同一聊天核验结果。原始 ID 和聊天正文不写入新增日志。

## 设置导航

- 设置改用自有非模态 Form，初始客户区 820 × 620，最小外窗 720 × 500；固定 200 像素分类栏与独立右侧表单，不再提供分类 ComboBox 或 760 宽度切换阈值。尺寸由系统 DPI/工作区约束处理，首页仍保持紧凑。
- 左侧六分类带稳定选中态与原生键盘/辅助技术语义；右侧标题显示完整分类名，英文导航采用 General / Recovery / Usage / Tasks / Diagnostics / About，避免放大字体时截断长分类名。
- 窗口关闭/Esc/返回经未保存内容确认后隐藏，保留页面控件、阅读位置和业务回调引用；主窗体退出时正常销毁所有者窗口。打开、关闭、重开不更改监测、额度或定时；明确保存指令仍沿用原有取消保护。
- 更新/未保存确认优先由可见设置窗口承载，避免提示被独立窗口挡住。没有为外观更换系统非客户区或标题栏。

## 验证与范围

- 核心 156 次断言通过，涵盖原有识别/输入/捕获/额度/定时/发布边界及新增跨后端身份比较。该数字包含代表参数重复，不是独立场景或设备数量。
- 自有窗口工作流验证连续 CDP 失败后只读 UIA 后备、定时/额度所有权保留、同标题不同原生聊天拒绝、丢失动作回复不重投及原聊天新 Running 确认；设置构建/关闭/重开、未保存编辑与明确保存的事务保护通过。原遮挡恢复、额度暂停/恢复和定时任务检查继续运行。
- 生产 worker 的自有 Electron 双页面检查覆盖遮挡/最小化状态动作、不读取恢复输入内容、问题阻断、底部最新 capacity 重试、稳定按钮身份、后台多行输入与侧栏导航。新增无关区域元数据、CSS 隐藏旧视图和当前区域真实双 ID 检查通过；前台和鼠标保持不变。
- 隔离候选 EXE 的设置渲染检查在本机实际 120 DPI（125%）下覆盖中文/英文六类、默认/最小窗口及最小窗口 15pt 字体；已视觉检查常规恢复页、额度页及放大英文导航。探针清除启动事件、停止计时器，最终 monitoring=False、target=null，不操作真实聊天。图片与探针保留在忽略的 `.local/settings-1.1.25-final` 等目录，不进入源码包。
- 真实故障聊天当时的两个 ID 来源仍无 DOM 证据，本轮没有在该聊天执行恢复；自有 Electron 验证不能替代该故障实机闭环。其复现与其他电脑实际 150%/200%、跨屏、高对比/读屏结果继续保留在 TODO。

本版构建、源码快照及 GitHub 发布沿用既有校验流程；发布结果由远端 tag、latest 接口和实际下载摘要核对，不用本地导出代替远端交付。
