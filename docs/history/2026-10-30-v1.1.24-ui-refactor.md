# 1.1.24 界面重构与每小时更新

用户授权实施[界面重构方案](../ui-refactor-plan.md)及每小时检查更新，基于 1.1.23 修改，保持 1.1.x 版本系列。

## 实现

- 首页恢复为受窗口约束的布局，额度位于进度之前；外层不滚动，状态、暂停、自动恢复与两个额度窗口可同时读取。按字体测量行高，窗口增高优先分配给进度，空间不足时收起次要帮助。保留采样/控件示意详情与完整记录入口
- 共用间距、分组标题、说明、复合阈值行、长文本详情和工作区适配；采用 Windows 原生窗口、按钮、键盘焦点和系统高对比色回退，不迁移 UI 框架
- 设置用 Panel 页面取代嵌入 Form，分成六类；窄窗口分类下拉、宽窗口侧栏，共用分类及阅读状态。高级定位与诊断工具展开查看；日志复制/导出靠前，原始诊断进入独立可复制窗口
- 继续指令有编辑缓冲和明确保存；切页/离开时可保存、放弃或继续编辑。保存失败保留草稿并反馈，已保存修改仍取消旧额度事务并关闭自动恢复，维持既有保护
- 一次性任务改用独立任务编辑窗口。保存前仍执行时间、目标、账号与聊天核验；失败保留输入，关闭后清除编辑器引用，避免异步回调写向已释放控件。任务模型及不明结果不重试规则未改
- `UiText.Apply` 排除日期时间、列表与输入控件，防止语言刷新给 DateTimePicker.Text 赋值并重置时间；完整多行翻译先匹配字典，再逐行处理。任务编辑的脏状态以可见的秒级时间比较
- 记录页使用筛选和固定导航，保留已有时间戳、横向/纵向位置与选择。额度详情可复制并保留阅读位置；更新说明/动作区自适应，仍以“稍后”为默认回车及取消操作。窗口/区域选择动作固定可达，长错误使用可复制详情
- 自动更新采用统一 `Updates.CheckInterval = 1h`；保留启动约 5 秒、开关、去重、跳过版本与安装交接。手动检查无更新/失败结果可在关于页显示，当前用户说明同步

一次性任务使用专门的辅助窗口，以完整空间编辑长指令；设置本身继续嵌入主窗口。原方案中的任务子视图以此形式落实。最近进度保留现有完整本轮检查列表，不改变周期性日志采集或事件内容。

## 验证

- 核心 152 次断言通过，覆盖识别/误点、输入让行、捕获取消、额度协议与事务、定时/范围、更新完整性及回退。断言数包含代表性参数重复，不是独立设备场景总数
- 完整自有窗口工作流通过：遮挡恢复、定时放行、额度暂停/保持/恢复、多任务顺序、不明结果不重复；新增设置边界检查覆盖构建/重排不改变待执行事务、编辑未提交、明确保存仍取消旧事务，以及时间选择器初始化/语言刷新保持选定时间
- 自有跨进程 UIA 检查通过只读观察、提前提交拒绝、已有内容保护和聊天变化失效。成功的焦点提交未在本轮发生，输入活动导致安全拒绝，不将其记为真实后台发送通过
- 本机隔离正式 EXE 布局检查覆盖中文/英文、560 × 500 默认客户区、520 × 491 最小客户区、15pt 放大字体、六类设置首尾、宽窗口侧栏及记录页。关键首页控件均处于实际父窗口内，首页无外层滚动；字号变化后额度数值和进度均保持可读
- 更新检查独立探针实际请求官方最新版本，验证关闭自动检查不改截止时间、并发请求被拒绝、首次请求后下一次安排约 3600 秒，以及手动结果就地呈现；没有下载或安装真实 CAR
- 辅助窗口探针覆盖无目标时任务保存被拒绝且窗口/输入保留、关闭后引用清理、更新窗口放大文字后动作可达、“稍后”默认/取消语义

布局探针使用独立数据目录、移除主窗体启动处理器并停止监测计时器。首页额度与目标展示为自造数据，结束时 `monitoring=False`、`target=null`，不操作用户聊天。原始代码、截图及输出仅在忽略目录 `.local/ui-refactor-1.1.24*`、`.local/aux-ui-refactor-1.1.24*`，不进入 Git 或源码包。

实际系统 DPI 为 96；放大字体不替代真实 125%/150%/200% 和跨屏测试。Windows 高对比和辅助技术需实机核对，保留在 TODO；已有故障机恢复、服务端额度重置及更新交接的外部验收保持原状态。本轮便携、源码及远程附件交付证据另记。
